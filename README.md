# Крипта влади

Криптовалюта в деклараціях народних депутатів IX скликання, міністрів і заступників міністрів з 2019 року:
хто тримає, хто позбувся і як це пояснив.

Сторінка статична: `index.html` містить усі дані й не робить запитів до API. Зовнішні ресурси — шрифти Google Fonts
і бібліотека d3 з cdnjs.

## Публікація на GitHub Pages

1. Покласти `index.html`, `.nojekyll` і цей `README.md` у корінь репозиторію.
2. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)`.

## Джерела даних

- Єдиний державний реєстр декларацій НАЗК (public.nazk.gov.ua), копія станом на жовтень 2026 року.
- Відкриті дані Верховної Ради (data.rada.gov.ua), kmu.gov.ua, офіційні сайти міністерств.
- Ціни: CoinGecko (поточні), Binance, OKX, Bitstamp (на 31 грудня кожного року), курс НБУ.

Методологія, фактчекінг і примітки — внизу сторінки.
